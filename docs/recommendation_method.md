## 0. 한 장 요약

```
사용자 입력 (연령대 a, 동반 유형 c, 여행 월 m, 시간대 t, 희망 지역)
        │
 ① 후보 집합      관광지·문화시설·레포츠, 좌표·시군구 코드 있는 곳
 ② 원지표 계산    치안(범죄율) · 교통(사고다발 EPDO) · 날씨(월별 위험 기상일) · 연령 LQ · 방문자
 ③ 정규화         전국 기준 분위수 절단 min-max → 모든 하위지표 r ∈ [0,1], 클수록 위험
 ④ 안전도 S       S = 1 − Σ w̃_k(a,c,t) · r_k     (w̃ 는 프로필별 가중치, 합 1)
 ⑤ 연령 적합도 F′ 평활 입지계수 LQ → F′ = 0.5 + ln LQ / (2 ln 4)
 ⑥ 인기도 P′      외지인·외국인 월평균 방문자의 전국 백분위
 ⑦ 결합           Score = α·pct(S) + β·pct(F′) + γ·pct(P′)   (α,β,γ = 0.5, 0.3, 0.2)
 ⑧ 선택           안전 게이트(하위 10% 제외) → 결정적 정렬 → 시군구당 최대 2곳 → 상위 N
        │
출력: 추천 목록 + 점수 분해(항별·하위지표별 기여) + 연령대 맞춤 주의 정보
```

## 1. 설계 원칙 — 산식이 반드시 지켜야 할 성질

산식의 모든 세부 선택은 아래 성질을 지키기 위해 정했습니다. 괄호 안은 이를 검사하는 테스트입니다.

| No | 성질 | 뜻 | 보장 장치 |
|---|---|---|---|
| P1 | 유계성 | S, F′, P′, Score 모두 0~1 (화면은 ×100) | 절단 정규화, 가중치 합 1 (`test_score_bounds`) |
| P2 | 단조성 | 다른 조건이 같을 때 위험 원지표가 늘면 안전도는 올라가지 않는다 | 모든 r 을 '클수록 위험'으로 통일, 가중치 ≥ 0 (`test_monotonic_in_crime`) |
| P3 | 필터 불변성 | 희망 지역을 바꿔도 같은 관광지의 점수는 그대로다 | 정규화·백분위·게이트 기준을 항상 전국 후보로 계산 (`test_region_filter_does_not_change_scores`) |
| P4 | 척도 일관성 | 연령대가 바뀌어도 안전도가 같은 0~100 척도다 | 프로필 가중치를 합 1로 재정규화 (`test_weights_sum_to_one…`) |
| P5 | 결측 중립성 | 자료가 없다는 이유로 유리해지지도, 크게 불리해지지도 않는다 | 결측 = 전국 중앙값 대체 + 커버리지 60% 미만 제외 (`test_missing_weather_is_neutral`) |
| P6 | 결정성 | 같은 입력이면 항상 같은 순위 | 점수 → 안전도 → content_id 순 정렬 (`test_ranking_is_deterministic`) |
| P7 | 분해 가능성 | 최종 점수와 안전도를 항목별 기여의 합으로 정확히 나눌 수 있다 | 선형 가중합 (`test_score_bounds`의 합 검사) |
| P8 | 이중 계산 금지 | 같은 정보를 입력과 검증에 동시에 쓰지 않는다 | 지역안전지수는 검증 전용 (5.1절) |
| P9 | 명목 ≈ 실효 가중치 | α·β·γ 가 실제로 순위에 그만큼 영향을 준다 | 백분위 결합 (4.1절, `test_rank_combine_equalizes_spread`) |

## 3. 단계별 계산

### 3.0 후보 집합

- `content_type_id ∈ {12 관광지, 14 문화시설, 28 레포츠}`. 음식점·숙박·쇼핑은 "방문할 관광지" 추천 범위 밖이라 뺍니다.
- 좌표(lat, lon)나 시군구 코드가 없으면 공간 결합을 할 수 없으므로 제외하고, `content_id` 중복은 제거합니다.

### 3.1 치안 — 유효인구 보정 + 경험적 베이즈 범죄율 (시군구 단위)

**① 분모: 유효인구.** 범죄 통계를 주민 인구로만 나누면, 관광객이 몰리는 지역의 범죄율이 과대평가됩니다(보고서 2.2.9 '통계 편향'). 방문자도 그 지역에 머무는 사람이므로 분모에 더합니다.

$$N^{\text{eff}}_s = P_s + \theta \cdot \bar V_s,\qquad \bar V_s = \frac{1}{12}\sum_{\text{최근 12개월 } y} \frac{V^{\text{외지인+외국인}}_{s,y}}{\text{일수}_y}$$

- 방문자수 API는 '일자별 순방문자'이므로, 월 합계를 그 달의 일수로 나누면 하루 평균 머무는 외부인 수가 됩니다.
- θ는 방문자가 하루 중 머무는 비율입니다. 기본값은 **0.5(가설)**이며, 민감도 분석에서 {0, 0.5, 1}을 비교합니다.
- 현지인은 이미 주민 인구에 들어 있으므로 더하지 않습니다(이중 계산 방지).

**② 분자: 5대 범죄.** 살인·강도·강간·강제추행·절도·폭력만 씁니다. 관광객 체감 위험과 관련이 적은 유형(예: 교통범죄, 지능범죄)이 섞이는 것을 막고, 매년 같은 정의로 비교할 수 있게 하기 위해서예요.

**③ 경험적 베이즈(EB) 축소 (Marshall, 1991).** 인구 1만 명 군에서는 범죄 몇 건 차이로 율이 크게 흔들립니다. 그래서 작은 지역일수록 전국 평균 쪽으로 당깁니다.

$$r_s=\frac{C_s}{N_s},\quad m=\frac{\sum C}{\sum N},\quad s^2=\frac{\sum N_s(r_s-m)^2}{\sum N},\quad A=\max\!\Big(s^2-\frac{m}{\bar N},0\Big)$$
$$w_s=\frac{A}{A+m/N_s},\qquad \hat r_s = m + w_s\,(r_s-m)\qquad(\times 10^5)$$

인구가 클수록 w_s → 1(자기 값 유지)이고, 작을수록 w_s → 0(전국 평균)입니다. (`test_eb_shrinks_small_areas_more`)

**④ 통계에 없는 시군구**는 0이 아니라 결측으로 둡니다(3.6절 결측 규칙).

> 생활안전지도 범죄주의 격자, CCTV 밀도는 4주차 확보 여부를 확인한 뒤 `crime_grid` 하위지표로 추가합니다. 추가하더라도 치안 요인 안의 가중치만 나눠 가지므로, 다른 요인의 비중은 바뀌지 않습니다.

### 3.2 교통 — 관광지 반경 사고다발 노출 + 시군구 기저 위험

**① 심각도 가중(EPDO).** 사고다발지역마다 사상자를 심각도로 가중합니다.

$$H_j = 12\cdot\text{사망}_j + 3\cdot\text{중상}_j + 1\cdot\text{경상}_j + 1\cdot\text{부상신고}_j$$

가중치는 대물피해환산(EPDO) 방식의 예시값입니다. 4주차에 도로교통공단 기준값을 확인해 `config.EPDO_WEIGHTS`를 교체합니다.

**② 관광지 반경 노출 (선형 거리 감쇠).**

$$T_i = \sum_{j:\,d_{ij}\le r}\Big(1-\frac{d_{ij}}{r}\Big) H_j,\qquad r = 0.5\text{km}$$

- 거리 d는 WGS84 위경도의 하버사인 거리입니다. 관광정보 API의 mapx는 경도, mapy는 위도예요.
- 감쇠를 넣는 이유는 두 가지예요. 반경 경계(0.49km와 0.51km)에서 값이 갑자기 끊기지 않게 하고, 가까울수록 방문 동선과 겹칠 가능성이 크다는 점을 반영합니다. (`test_hotspot_distance_decay`)
- 반경 r은 민감도 분석에서 {0.3, 0.5, 1.0}km를 비교합니다.

**③ 시군구 기저 위험.** 다발지역은 기준 이상으로 사고가 밀집한 곳만 수록돼요. 그래서 T_i = 0이 '사고 없음'을 뜻하지는 않아요(보고서 2.2.2 ④). 이 0값 해석 문제를 시군구 평균으로 보완합니다.

$$A_s = \frac{\sum_{j\in s} H_j}{N^{\text{eff}}_s}\times 10^5$$

**④ 취약계층 하위지표.** 사고유형이 `보행어린이·스쿨존어린이`인 것만 모은 T^child, `보행노인`인 것만 모은 T^elder를 따로 계산합니다. 식은 ②와 같습니다. 이 둘은 기본으로 꺼져 있고, 해당 프로필에서만 켜집니다(3.5절).

### 3.3 날씨 — 여행 월의 위험 기상 빈도 (관측소 × 월)

사고 건별 일시가 공개되지 않아 '사고 당일 날씨'를 매칭할 수 없어요(보고서 2.3). 그래서 날씨 위험을 **"그 달에 위험 기상이 나타나는 빈도(기후 노출)"**로 정의합니다.

| 하위지표 | 판정 (ASOS 일자료) | 근거 |
|---|---|---|
| heat 폭염 | 일 최고기온 ≥ 33℃ | 폭염특보 기준의 일자료 근사 |
| rain 호우 | 일 강수량 ≥ 80mm | 호우특보(3h 60mm / 12h 110mm)의 일 단위 근사 |
| cold 한파 | 일 최저기온 ≤ −12℃ | 한파주의보 기준 |
| snow 대설 | 일 신적설 ≥ 5cm | 대설주의보 기준 |

$$W^{(k)}_{\text{stn},m} = \frac{\#\{\text{최근 10년 } m\text{월 중 기준 충족일}\}}{\#\{\text{최근 10년 } m\text{월 관측일}\}}$$

- 관광지에는 **최근접 관측소**의 값을 씁니다. 가장 가까운 관측소도 50km보다 멀면 날씨는 결측으로 둡니다.
- 특보 기준은 일자료로 근사한 값이에요. 이후 기상특보 발효 이력(특보구역 → 시군구 매핑)이 확보되면 '특보 발효일 비율'로 바꿀 수 있습니다.

### 3.4 시간 — 전국 공통 계수의 올바른 쓰임

범죄 시간대 통계는 전국 단위라서(보고서 2.2.2 ①), 모든 관광지에 같은 계수를 곱하게 됩니다. **모든 관광지의 총위험에 같은 수를 곱하면 순위는 전혀 바뀌지 않습니다.** 그래서 시간대는 위험값이 아니라 **요인 간 가중치 배수**로 넣습니다.

$$\rho^{\text{야간}}_k = \frac{\text{야간 발생 비중}}{\text{야간 시간 비중}}\quad(\text{범죄·교통 하위지표}),\qquad \rho^{\text{야간}}_{\text{heat}} = 0.3$$

야간에는 범죄·교통 비중이 커지고 폭염 비중이 줄어요. 그래서 범죄율은 낮지만 폭염이 잦은 곳과, 그 반대인 곳 사이의 순위가 바뀝니다. 현재 값(범죄 1.5, 교통 1.3)은 가설이며, 4주차에 경찰청·TAAS 시간대 통계로 산출합니다.

> 지역 × 시간대 교차 통계(예: TAAS 시군구별 시간대 사고)가 확보되면, 시간 요인을 시군구별 하위지표로 바꿀 수 있습니다.

### 3.5 정규화 → 프로필 가중치 → 안전도 S

**① 정규화.** 모든 하위지표를 0~1로 바꾸고 '클수록 위험'으로 통일합니다.

$$r_{ik} = \operatorname{clip}\!\left(\frac{g(x_{ik}) - Q_{05}}{Q_{95}-Q_{05}},\,0,\,1\right),\qquad g=\log(1+x)\ \text{(건수·율)},\ g=x\ \text{(날씨 비율)}$$

- **분위수 절단 (5%·95%)**: 극단값 하나가 나머지 전체를 0 근처로 눌러 버리는 min-max의 약점을 막아요.
- **log1p**: 오른쪽 꼬리가 긴 건수·율 분포를 펴 줍니다. 0은 0으로 유지돼요.
- **기준 모집단은 지표의 공간 단위별로 다르게 잡습니다.**
  - 시군구 지표는 전국 시군구를 기준으로 합니다. 관광지 수로 가중하지 않으므로, 관광지가 많은 시군구가 분포를 지배하지 않아요.
  - 관광지 지표는 전국 후보 관광지를 기준으로 합니다.
  - 날씨 지표는 전국 관측소 × 12개월을 기준으로 합니다. 그래서 1월의 폭염 0처럼 계절 차이가 그대로 보존돼요.
- 대부분이 0인 희소 지표(예: 보행노인 다발지역)는 Q95 = Q05가 될 수 있어요. 이때는 상한을 최댓값으로 올립니다. (`test_robust_minmax_handles_sparse_zeros`)

**② 프로필 가중치.**

$$\tilde w_k(a,c,t) = \frac{W_{f(k)}\, b_k\, m_k(a,c,t)}{\sum_j W_{f(j)}\, b_j\, m_j(a,c,t)},\qquad m_k = \max\big(m^{\text{연령}}_k(a),\, m^{\text{동반}}_k(c)\big)\cdot \rho^{t}_k$$

- **W_f**는 요인 가중치예요. 치안·교통·날씨 각 1/3로 초기 동일 가중입니다.
- **b_k**는 요인 안의 기본 가중치예요. 기본으로 켜진 지표끼리 합이 1이 되도록 정합니다.
  - 치안: 범죄율 1
  - 교통: 주변 사고다발 0.5, 시군구 사고 0.5
  - 날씨: 네 지표 각 0.25
- 배수가 모두 1이면 세 요인이 정확히 1/3씩입니다. (`test_neutral_profile_gives_equal_factor_weights`)
- **연령·동반 배수는 곱하지 않고 최댓값을 씁니다.** 일행의 위험은 가장 취약한 구성원이 결정한다고 보기 때문이에요. 곱하면 '70대 + 고령 부모 동반'처럼 같은 취약성을 두 번 세게 됩니다.
- 시간대 배수는 노출 시간대라는 다른 성격의 보정이라 곱합니다.
- 보행어린이·보행노인 지표는 기본 배수 0에서 시작하고, 해당 프로필에서만 켜집니다. 전체 사고다발 지표의 부분집합이므로, 켜지는 순간 그 계층에 대한 **의도된 강조**가 됩니다.
- 전체를 합 1로 다시 맞추므로 프로필이 바뀌어도 안전도 척도가 같습니다(P4). 대신 가중치는 절대 위험의 크기가 아니라 **"이 사용자가 무엇을 더 조심해야 하는가"**를 뜻하게 돼요.

**연령·동반 배수 (현재 가설값 → 4주차 추정 방법)**

| 프로필 | 배수 | 추정 방법 (`relative_risk_multiplier`) |
|---|---|---|
| 50대 | 폭염 1.2 | |
| 60대 | 폭염 2.0, 한파 1.5, 대설 1.5, 보행노인 1.0 | 온열·한랭질환 감시 연령별 환자 비중 ÷ 인구 비중 |
| 70대 이상 | 폭염 2.5, 한파 2.0, 대설 2.0, 보행노인 1.5 | 같음, TAAS 연령별 보행 사상자 비중 ÷ 인구 비중 |
| 혼자 | 범죄율 1.2 | (문헌·설문 근거 확보 전까지 가설) |
| 가족(아동 동반) | 보행어린이 1.5, 폭염 1.5 | TAAS 어린이 보행 사상자 상대위험 |
| 가족(고령 부모 동반) | 보행노인 1.5, 폭염 2.0, 한파 1.5, 대설 1.5 | 60대 이상과 같음 |

상대위험 추정식은 `m = clip(피해자 중 연령 a 비중 / 인구 중 연령 a 비중, 1, 3)`입니다. 1 미만은 1로 올려서 취약하지 않은 집단의 위험을 깎지 않고, 3을 넘는 값은 3으로 제한합니다.

**③ 결측 처리와 안전도.**

$$\hat r_{ik}=\begin{cases} r_{ik} & \text{값이 있으면}\\ \operatorname{median}_i(r_{ik}) & \text{결측이면 (전국 후보 중앙값)}\end{cases}\qquad S_i = 1-\sum_k \tilde w_k\,\hat r_{ik}$$
$$\text{커버리지 } c_i = \sum_{k:\,r_{ik}\text{ 존재}} \tilde w_k,\qquad c_i<0.6 \Rightarrow \text{추천 제외}$$

결측을 빼고 남은 지표로만 평균을 내면, 결측 자리를 그 관광지의 다른 지표 평균으로 채우는 셈이에요. 실제로 초기 구현에서는 날씨 자료가 없는 관광지가 1위로 올라갔습니다. 중앙값 대체는 결측을 '전국 보통 수준'으로 두어, 유리하지도 불리하지도 않게 합니다(P5).

### 3.6 연령 적합도 F′ — 평활 입지계수 (시군구 × 연령대)

방문자수 API에는 성·연령 구분이 없어요(보고서 3주차 검증). 그래서 **데이터랩 연령 비중 × 방문자수 API 인원**으로 연령대별 인원을 복원합니다.

$$v_{a,s} = \text{share}_{a,s}\cdot v_s,\qquad \pi_a=\frac{\sum_s v_{a,s}}{\sum_s v_s}\ (\text{전국 연령 비중})$$
$$\tilde p_{a,s} = \frac{v_{a,s}+\lambda\,\pi_a}{v_s+\lambda},\qquad LQ_{a,s}=\frac{\tilde p_{a,s}}{\pi_a},\qquad \lambda = 5{,}000\text{명}$$
$$F'_{a,s} = \operatorname{clip}\!\Big(0.5+\frac{\ln LQ_{a,s}}{2\ln 4},\,0,\,1\Big)$$

- **LQ > 1**이면 연령 a가 전국 평균보다 상대적으로 많이 찾는 지역이에요. "사람이 많은 곳"이 아니라 "이 연령대의 비중이 높은 곳"을 재므로 인기도와 겹치지 않습니다.
- **평활 λ**: 방문자가 적은 지역일수록 전국 비중 쪽으로 당겨 표본 잡음을 줄여요. 개념은 3.1절의 EB와 같습니다.
- **로그 변환**: LQ 2배와 1/2배가 중립(0.5)에서 같은 거리만큼 떨어집니다. LQ=4 이상이면 1, 1/4 이하이면 0이에요. (`test_lq_mapping_is_symmetric`)
- **연령 자료가 없는 시군구**는 F′ = 0.5(중립)로 두고 '연령 자료 없음'으로 표시합니다.
- **한계**: 같은 시군구 안의 관광지는 F′가 같습니다. 관광지 유형별 연령 선호(예: 데이터랩 목적지 분류별 연령 비중)가 확보되면 F′_i = F′_s × 유형 친화도로 확장합니다.

### 3.7 인기도 P′ · 혼잡도 (시군구)

$$P'_s = \operatorname{pct}_s\Big(\tfrac{1}{12}\textstyle\sum_{y} V^{\text{외지인+외국인}}_{s,y}\Big),\qquad \text{혼잡도}_{s,m} = \dfrac{V_{s,m}}{\tfrac{1}{12}\sum_y V_{s,y}}$$

- 현지인을 빼는 이유는 인구가 많은 도시가 '인기 관광지'로 잘못 잡히지 않게 하기 위해서예요.
- 방문자 수 분포가 극단적으로 치우쳐 있어서(대도시 대 군 지역) 백분위를 씁니다.
- 방문자 데이터는 일자별 순방문자라 광역·기초 값을 합산할 수 없어요(2박 3일 = 3명). 그래서 **기초지자체 값만** 씁니다.
- 여행 월의 혼잡도가 1.3을 넘으면 '혼잡(성수기)' 표시를 붙입니다. 표시만 하고 점수에는 넣지 않아요(인기도와의 이중 계산을 피하기 위해서예요).

## 4. 결합 · 게이트 · 정렬 · 다양성

### 4.1 결합: 백분위 가중합

$$\text{Score}_i = \alpha\cdot\operatorname{pct}(S_i) + \beta\cdot\operatorname{pct}(F'_i) + \gamma\cdot\operatorname{pct}(P'_i),\qquad \alpha+\beta+\gamma = 1,\ (0.5,\,0.3,\,0.2)$$

백분위는 전국 후보 관광지 안에서 구하고, 동률은 평균순위로 처리합니다.

**왜 원값(S, F′, P′)을 그대로 더하지 않는가.** 가중합에서 한 항이 순위를 움직이는 힘은 **가중치 × 그 항의 퍼짐**에 비례해요. 샘플 데이터로 측정한 실효 가중치(4.4절)는 다음과 같았어요.

| 70대 이상 · 고령 부모 동반 · 8월 | α S | β F′ | γ P′ |
|---|---|---|---|
| 명목 가중치 | 0.50 | 0.30 | 0.20 |
| 원값 결합의 실효 가중치 | 0.43 | **0.09** | **0.48** |
| 백분위 결합의 실효 가중치 | 0.76 | 0.28 | −0.04 |

- **원값 결합**에서는 F′의 폭이 좁고(LQ 평활) P′는 0~1에 고르게 퍼져 있어요. 그래서 β = 0.3을 줘도 연령 적합도가 거의 반영되지 않았고, 인기도가 명목의 두 배 넘게 순위를 좌우했어요.
- **백분위 결합**은 세 항의 퍼짐을 같게 맞추므로, 남는 차이는 **항 사이의 상관**뿐이에요. 샘플에서 P′의 실효 가중치가 0 근처인 이유는 인기 지역일수록 안전도가 낮아(음의 상관) 서로 상쇄되기 때문입니다. 이것은 '안전'과 '인기'가 서로 반대 방향이라는 데이터의 사실이며, 대시보드에 실효 가중치로 그대로 보여 줍니다.
- 원값 결합(`combine="value"`)은 비교용으로 남겨 두었어요.

### 4.2 안전 게이트 (비보상 규칙)

가중합은 보상형이라, 안전도가 매우 낮아도 인기·적합도가 높으면 상위에 오를 수 있어요. 이를 막기 위해 **같은 프로필 기준 전국 안전도 하위 10%**(S < Q₁₀)는 기본 목록에서 제외하고 '⚠ 안전 주의'로 표시합니다. 사용자가 원하면 포함할 수 있어요.

- 기준을 프로필마다 다시 계산하는 이유는, 가중치가 바뀌면 S 분포도 바뀌기 때문이에요.
- '위험 지역'이 아니라 '안전 주의'로 표기하고, 요인별 원인을 함께 보여 줍니다(지역 낙인 방지, 보고서 2.2.9).

### 4.3 정렬과 다양성

1. **결정적 정렬**: Score 내림차순, 동점이면 S 내림차순, 그래도 같으면 content_id 오름차순. 부동소수 오차는 소수 9자리에서 반올림한 뒤 비교합니다(P6).
2. **다양성 제약**: 정렬 순서대로 훑으며 같은 시군구가 2곳을 넘으면 건너뜁니다. 치안·F′·P′가 시군구 단위라 같은 시군구 관광지끼리 점수가 거의 같아서, 제약이 없으면 한 지역이 목록을 독점해요.
3. **지역 필터**는 이 단계에서 고르기만 합니다. 점수를 다시 계산하지 않아요(P3).

### 4.4 설명: 점수 분해

$$\text{Score}_i = \underbrace{\alpha\,\operatorname{pct}(S_i)}_{\text{안전}} + \underbrace{\beta\,\operatorname{pct}(F'_i)}_{\text{적합}} + \underbrace{\gamma\,\operatorname{pct}(P'_i)}_{\text{인기}},\qquad 1-S_i = \sum_k \underbrace{\tilde w_k\,\hat r_{ik}}_{\text{하위지표 감점}}$$

**실효 가중치**는 최종 점수 분산 중 각 항이 설명하는 몫이에요(합 1).

$$e_X = \frac{\operatorname{Cov}(c_X,\ \text{Score})}{\operatorname{Var}(\text{Score})}$$

명목 가중치와 함께 보고해서, 가중치를 바꿨을 때 실제로 무엇이 바뀌는지 알 수 있게 합니다.

## 5. 검증 계획 (정답 레이블이 없는 지수형 문제)

### 5.1 수렴 타당도

- 시군구 원지표(범죄율, 시군구 사고)와 **행정안전부 지역안전지수** 해당 분야 등급(1 안전 ~ 5 위험) 사이의 스피어만 상관을 봅니다. 기대 부호는 양(+)이고, 기준은 ρ ≥ 0.5예요.
- 지역안전지수는 입력에 넣지 않았으므로 순환 논리가 없습니다(P8).
- 등급이 같은 유형 지자체(시·군·구) 안의 상대 등급이므로, 유형별로도 따로 계산합니다.

### 5.2 민감도 (순위 안정성)

| 흔드는 대상 | 범위 | 지표 | 판정 기준 |
|---|---|---|---|
| α, β, γ | 단체 전 격자 (0.1 간격, 66조합) | 상위 10 자카드, 전체 스피어만 | 기준안 ±0.1 평균 자카드 ≥ 0.7 |

기준에 못 미치면 "추천이 가정에 민감하다"고 보고, 해당 파라미터를 실측값으로 바꾸거나 화면에 불확실성을 표시합니다.

### 5.3 몬테카를로 불확실성 전파

$$(\alpha,\beta,\gamma)\sim\operatorname{Dir}(\kappa\cdot(0.5,0.3,0.2)),\qquad \tilde w\sim\operatorname{Dir}(\kappa\cdot\tilde w_0),\qquad \kappa=30,\ 200\text{회}$$

관광지별로 **상위 10 진입 확률**과 **순위 5·50·95% 구간**을 구합니다. 진입 확률이 90% 이상이면 '가중치와 무관하게 추천되는 곳', 50% 안팎이면 '가중치 선택에 따라 갈리는 곳'으로 해석해요.

|---|---|
| 70대 이상 · 8월 | 폭염일 비율이 높은 곳의 순위가 20대보다 내려간다 |
| 가족(아동 동반) | 보행어린이 다발지역이 가까운 곳의 안전도가 내려간다 |

## 6. 계산 예시 (샘플 데이터 · 70대 이상 · 가족(고령 부모 동반) · 8월 · 주간)

> 가상 샘플 데이터로 계산한 값입니다. 실제 지역·수치가 아닙니다.

**가중치 w̃** (합 1)

| 범죄율 | 주변 사고다발 | 시군구 사고 | 보행노인 | 폭염 | 호우 | 한파 | 대설 |
|---|---|---|---|---|---|---|---|
| 0.216 | 0.108 | 0.108 | 0.162 | 0.135 | 0.054 | 0.108 | 0.108 |

- 폭염 배수는 연령 2.5와 동반 2.0 중 큰 값인 2.5, 보행노인 배수는 연령 1.5와 동반 1.5 중 1.5를 씁니다.
- 중립 프로필(20대·친구·연인)이면 범죄율 0.333, 교통 두 지표 각 0.167, 날씨 네 지표 각 0.083이에요.

**1위 '가상 관광지 060' (가상시 36)**

| 하위지표 | 원값 | r | w̃·r (감점) |
|---|---|---|---|
| 범죄율 | 542.9 /10만 | 0.149 | 0.032 |
| 주변 사고다발 · 보행노인 | 0 | 0 | 0 |
| 시군구 사고 | 44.6 /10만 | 0.118 | 0.013 |
| 폭염 (8월, 관측소 9.4km) | 49.1% | 1.000 | 0.135 |
| 호우 | 5.3% | 0.574 | 0.031 |
| 한파 · 대설 | 0% | 0 | 0 |

- 안전도: S = 1 − (0.032 + 0.013 + 0.135 + 0.031) = **0.789**
- 연령 적합도: LQ = 1.570 이므로 F′ = 0.5 + ln 1.570 / (2 ln 4) = **0.663**
- 인기도: P′ = **0.769**
- 백분위: pct(S) = 0.938, pct(F′) = 0.933, pct(P′) = 0.481
- 최종 점수: 0.5×0.938 + 0.3×0.933 + 0.2×0.481 = 0.469 + 0.280 + 0.096 = **0.845**
- 같은 관광지를 20대·친구·연인으로 계산하면 전국 13위예요. 70대에서 1위가 된 이유는 이 지역의 70대 LQ(1.57)가 높고, 범죄·교통 위험이 낮기 때문이에요. 폭염 감점이 가장 크게 표시되므로, 화면에서는 '8월 폭염 주의'를 함께 안내합니다.

| 초안 | v3 | 이유 |
|---|---|---|
| S = 100 − 정규화(Σ w·위험) | 하위지표별 정규화 후 가중합, 가중치 합 1 | 합을 먼저 하고 정규화하면 요인 간 단위 차이가 그대로 섞인다 |
| 정규화 방법 미정 | log1p + 5·95% 분위수 절단 min-max, 공간 단위별 전국 기준 | 이상치·치우친 분포 대응, 필터 불변성 |
| 범죄 건수 (인구 보정 예정) | 유효인구(주민 + θ·방문자) 분모 + EB 축소 | 관광지 과대평가 편향과 소규모 군 잡음 동시 해결 |
| 연령 위험 보정 "가중 확대" | 연령·동반 배수의 최댓값 × 시간대 배수, 전체 재정규화, 공공 통계 상대위험으로 추정 | 이중 계산 방지, 척도 일관성, 근거 있는 값 |
| 시간 요인을 위험값으로 | 가중치 배수로 | 전국 공통 계수는 위험값에 곱하면 순위에 영향이 없다 |
| 날씨 = 사고 시점 기상 매칭 | 여행 월의 위험 기상일 비율(기후 노출) | 사고 건별 일시 미공개 |
| F = 비중 ÷ 전국 비중 | 평활 LQ의 로그 변환, 결측은 중립 0.5 | 소표본 잡음, 대칭성 |
| P = 월평균 방문자 백분위 | 외지인·외국인만, 기초지자체만 | 인구 효과 제거, 광역·기초 합산 불가 |
| Score = α S′ + β F′ + γ P′ | 백분위 결합 + 실효 가중치 보고 | 명목 가중치와 실효 가중치의 괴리 해소 |
| (없음) | 안전 게이트, 결정적 정렬, 다양성 제약, 결측 규칙 | 보상형 약점, 재현성, 한 지역 독점 방지, 결측 이득 차단 |
| 지역안전지수를 종합 안전에 사용 | 검증 전용 | 입력과 검증 기준을 분리해 순환 논리 방지 |
