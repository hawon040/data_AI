# 개인정보 처리방침 (초안)

> 웹 화면 `/privacy`와 같은 내용이다(원본: `web/src/lib/privacyPolicy.ts`). 둘을 함께 고친다.
> 코드가 실제로 하는 일(`tourapi/usage_events.py`, `web/src/lib/usageApi.ts`)만 적었다. **법률 검토를 받은 문서가 아니다.**

## 1. 수집하는 항목과 방법
TourLink는 사용자가 기록 참여에 동의한 경우에만, 평가를 보내거나 길찾기를 누를 때 아래 항목을 익명으로 저장한다.
- 성별(여성·남성)과 연령대(10대~60대 이상 구간)
- 평가하거나 길찾기를 누른 관광지 이름과 그 지역 코드
- 행동 종류(평가 또는 길찾기), 평가 점수(1~5점), 행동한 시각
- 이 브라우저가 처음 만든 임의의 식별 번호(일행 번호가 붙음). 같은 사람이 같은 날 같은 행동을 반복해 통계가 부풀려지는 것을 막는 데만 쓰고, 사람을 알아내는 데 쓰지 않는다.

## 2. 수집하지 않는 것
- 이름, 연락처, 이메일, 생년월일·정확한 나이, 계정 정보
- 위치 좌표, 광고 식별자
- IP 주소(기록 저장소에 넣지 않는다. 4번 참고)

## 3. 이용 목적
- 지역·관광지별로 연령대와 성별 이용 경향을 집계해 다음 추천을 보정한다. 기록이 적을 때는 기본값으로 추천하고, 쌓일수록 실제 기록을 더 반영한다.
- 개별 기록은 다른 사용자에게 보여 주지 않으며, 관광지의 평가 점수는 평가가 5건 이상일 때만 화면에 표시한다.

## 4. 요청 제한
과도한 전송을 막기 위해 IP 주소를 해시한 값으로 요청 횟수를 세며, 이 값은 요청 횟수를 세는 약 1시간 동안만 서버 메모리나 캐시에 두고 기록 저장소에는 넣지 않는다.

## 5. 보관 기간과 파기
- 기록은 **[팀 확인 필요]** 동안 보관하고 그 뒤 삭제한다. (현재 자동 삭제 기능은 없다.)
- 집계 통계는 개인을 식별할 수 없는 형태로만 추천에 사용한다.

## 6. 동의 철회
- 추천 화면 위의 '참여 끄기'를 누르면 그 뒤로는 기록을 보내지 않는다. 브라우저의 사이트 데이터를 지우면 임의의 식별 번호도 사라진다.
- 이미 저장된 기록은 개인을 식별할 수 없게 저장되어 있어 개별 삭제가 어렵다. 삭제를 요청하려면 문의처로 연락한다.

## 7. 외부 서비스
지도와 길찾기는 카카오 서비스로 연결되고, 날씨·미세먼지는 기상청과 에어코리아의 공공데이터를 쓴다. 해당 서비스를 이용할 때는 각 서비스의 정책이 적용된다.

## 8. 문의처와 시행일
- 운영자·문의처: **[팀 확인 필요]**
- 시행일: **[팀 확인 필요]**

---

## 팀이 정해야 할 것 (시행 전)
1. **운영자 이름과 문의처, 시행일**
2. **보관 기간.** 정하면 `usage_events`에 만료 인덱스(TTL)를 걸어 실제로 지켜야 한다. 지금은 자동 삭제가 없다.
3. **만 14세 미만.** 연령대 "10대"에는 14세 미만이 포함된다. 14세 미만의 기록을 받지 않을지, 받는다면 법정대리인 동의를 어떻게 받을지 정해야 한다. 지금 코드는 나이를 구분하지 않는다.
4. **개별 삭제 요청 처리 방식.** 임의 식별 번호로 삭제하려면 요청자가 번호를 알려 줘야 한다. 지금은 그 경로가 없다.
5. 법률 검토(해당 서비스의 규모·대상에 따라 신고·고지 의무가 달라질 수 있다).
