# 실제 데이터로 추천하기

가상 샘플 대신 실제 관광지를 추천하려면 아래 원본 파일을 `data/raw/`에 넣고 빌드 스크립트를 실행하면 됩니다. 그러면 대시보드와 `scripts/recommend.py`가 자동으로 실제 데이터를 씁니다.

## 1. 준비물

| 저장할 파일 (`data/raw/`) | 내용 | 받는 곳 | 방법 |
|---|---|---|---|
| `attraction.csv` | 관광지·문화시설·레포츠 목록과 좌표 | 국문 관광정보 서비스 API (data.go.kr/data/15101578) | `--collect`로 자동 수집 |
| `visitor_monthly.csv` | 시군구별 최근 12개월 방문자(현지인·외지인·외국인) | 지역별 방문자수 API (data.go.kr/data/15101972) | `--collect`로 자동 수집 |
| `population.csv` | 시군구별 주민등록 인구 | 행정안전부 주민등록 인구통계 (jumin.mois.go.kr) | 시군구 단위 CSV 다운로드 |
| `crime_region.csv` | 범죄 발생 지역별 통계(가로형 원본 그대로) | data.go.kr/data/3074462 | 파일 다운로드 |
| `accident_hotspot.csv` | 전국 교통사고다발지역 | data.go.kr/data/15029185 | 파일 다운로드 |
| `asos_daily.csv` | 최근 10년 종관기상관측(ASOS) 일자료, 전 지점 | 기상자료개방포털 (data.kma.go.kr) | 일자료 CSV 다운로드 |
| `asos_stations.csv` | ASOS 지점 정보(위도·경도) | 기상자료개방포털 지점정보 | CSV 다운로드 |
| `age_mix.csv` | 시군구별 방문자 연령대 비중 | 한국관광 데이터랩 (datalab.visitkorea.or.kr) | 아래 형식으로 정리 |
| `safety_index.csv` (선택) | 지역안전지수 분야별 등급 — 검증 전용 | 행정안전부 | 아래 형식으로 정리 |

- 원본 컬럼명은 그대로 두세요. 로더(`src/tourrec/loaders.py`)가 후보 이름 목록에서 찾아 읽어요. 못 찾으면 실제 컬럼 목록을 보여 주는 오류가 나는데, 그때 후보 목록에 이름을 하나 추가하면 됩니다.
- 인코딩은 utf-8과 cp949를 모두 자동으로 처리해요.

**`age_mix.csv` 형식** (데이터랩 화면이나 다운로드 값을 세로로 정리)

```
시도,시군구,연령대,비중
강원특별자치도,춘천시,20대,18.4
강원특별자치도,춘천시,70대 이상,6.1
```

- 비중은 %나 0~1 둘 다 됩니다. 시도 명칭은 옛 이름(강원도·전북)이어도 돼요.
- 시군구 코드를 알면 `sgg_code,연령대,비중` 형식으로 써도 됩니다.

**`safety_index.csv` 형식**

```
시도,시군구,분야,등급
서울특별시,종로구,범죄,3
서울특별시,종로구,교통사고,2
```

## 2. 실행

```bash
cp .env.example .env            # DATA_GO_KR_KEY 에 공공데이터포털 'Decoding' 키 입력
pip install -r requirements.txt
python scripts/build_processed.py --collect --crime-year 2024
python scripts/recommend.py --age "70대 이상" --companion "가족(고령 부모 동반)" --month 8
streamlit run app/streamlit_app.py
```

빌드가 끝나면 `data/processed/_quality_report.txt`에 품질 점검 결과가 남아요(보고서 2.3②). 아래 항목을 확인하세요.

- 범죄·연령 비중의 시군구 결합 수와 미매칭 명칭 목록
- 사고다발지역·관광지 좌표 중 국내 범위를 벗어난 건수
- 관광지 좌표 결측률과 중복 ID

미매칭 명칭이 있으면 `loaders.py`의 `SIDO_ALIASES`나 `EXTRA_NAMES`에 추가하고 다시 빌드하세요.

## 3. 명칭·코드 통일 규칙 (보고서 2.2.5 구현)

| 문제 | 처리 |
|---|---|
| 시도 약칭·정식명 혼재 ("서울 종로구" ↔ "서울특별시 종로구") | 인구 표의 정식명에서 약칭 사전을 자동 생성 |
| 특별자치도 명칭 변경 (강원도 → 강원특별자치도, 전라북도 → 전북특별자치도) | 옛 명칭을 같은 코드로 매핑 |
| 관할 변경 (군위군: 경북 → 대구) | "경북 군위군" 열을 대구 군위군(27720)에 합산 |
| 일반구 합산·분리 차이 (범죄 "수원시" ↔ 관광정보 "수원시 장안구") | 모든 자료를 상위 시 코드(끝자리 0)로 올림 |
| 범죄 통계의 '외국 ○○' 열 | 제외 |
| 5대 범죄 | 중분류에서 살인·강도·강간·강제추행·절도·폭력(상해·폭행·체포감금·협박·약취유인·폭력행위등·공갈)만 사용, 손괴·방화 제외 |
| 사고다발지역 연도 | 최신 사고연도만 사용(다발지역은 해마다 다시 선정) |
| ASOS 지점 이전 | 종료일이 없는 현재 위치 사용 |

## 4. 클라우드 세션에서 실행하려면

이 저장소를 Claude Code 클라우드 세션에서 실행하려면 두 가지 설정이 필요합니다.

1. **네트워크 허용**: 환경 설정의 Network access에서 `apis.data.go.kr`을 허용 도메인에 추가하세요. 파일까지 내려받으려면 `www.data.go.kr`, `data.kma.go.kr`도 필요해요.
2. **인증키 설정**: 환경 변수 `DATA_GO_KR_KEY`로 등록하세요. 키를 채팅에 붙여 넣지는 마세요.
