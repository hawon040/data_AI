# South Korea map credits

`korea-map.svg` is a blank administrative map of territory claimed by South
Korea. It is in the public domain.

- Source: [Wikimedia Commons — Map of South Korea-blank.svg](https://commons.wikimedia.org/wiki/File:Map_of_South_Korea-blank.svg)
- Original work: Ksiom; adapted by Kwj2772
- License: Public domain

The random-trip board places sample attraction markers on this map using their
latitude and longitude. Sample destination data is illustrative.
